# Автоматический приём банковских SMS

Инструкция на один раз. После неё операции попадают в приложение без ручного ввода:
пришло SMS от банка — телефон сам переслал его, приложение при открытии показало
готовый список операций, вы только подтверждаете.

## Как это устроено

```
SMS от банка  →  MacroDroid на телефоне  →  /api/inbox (ваш Vercel)
                                                    ↓
                                            Upstash Redis (временно)
                                                    ↓
                                    приложение забирает при открытии
                                                    ↓
                              разбор на устройстве → окно сверки → база
```

Сервер только передаёт текст. Он не разбирает суммы, не хранит операции и ничего
не знает о ваших финансах — вся логика осталась в приложении на телефоне.

---

## Шаг 1. Выложить проект на Vercel

1. Залейте репозиторий на GitHub.
2. Зайдите на vercel.com, войдите через GitHub.
3. **Add New → Project**, выберите репозиторий.
4. Framework Preset должен определиться как **Vite**. Ничего не меняйте, нажмите **Deploy**.
5. Запомните адрес, который выдаст Vercel — например `https://pva-finance.vercel.app`.

Папка `api/` подхватывается автоматически, отдельно настраивать её не нужно.

## Шаг 2. Создать хранилище Upstash

Upstash — временный почтовый ящик между телефоном и приложением. Бесплатного тарифа
хватает с огромным запасом: несколько сотен сообщений в месяц против лимита в десятки тысяч.

1. Зайдите на upstash.com, зарегистрируйтесь.
2. **Create Database**, тип **Redis**, регион выберите ближе к себе (подойдёт любой европейский).
3. На странице базы найдите раздел **REST API**.
4. Скопируйте два значения: `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`.

## Шаг 3. Придумать пароль ящика

Это ваш личный секрет — по нему сервер отличает ваши сообщения от чужих.
Возьмите длинную случайную строку, не менее 24 символов, например:

```
w7Kq2mBvR4xTzN9pL6hJaC3f
```

Не используйте что-то угадываемое. Этот пароль будет лежать в настройках MacroDroid,
так что относитесь к нему как к паролю от почты.

## Шаг 4. Прописать три переменные в Vercel

В проекте на Vercel: **Settings → Environment Variables**. Добавьте три штуки:

| Имя | Значение |
|---|---|
| `UPSTASH_REDIS_REST_URL` | из шага 2 |
| `UPSTASH_REDIS_REST_TOKEN` | из шага 2 |
| `WALLET_INBOX_KEY` | пароль из шага 3 |

Выберите все окружения (Production, Preview, Development). После сохранения зайдите
в **Deployments** и нажмите **Redeploy** у последней сборки — без этого переменные не подхватятся.

## Шаг 5. Вписать пароль в приложение

Откройте приложение, ⚙️ Настройки → **Автоматический приём SMS** →
поле «Пароль почтового ящика» → вставьте тот же пароль из шага 3 → **Сохранить ключ**.

Нажмите **Проверить сейчас**. Если всё верно, появится «Новых сообщений нет».
Если «Сервер не принял пароль» — пароль в приложении и в Vercel различаются.
Если «Не удалось связаться с почтовым ящиком» — не сделали Redeploy после шага 4.

## Шаг 6. Настроить MacroDroid на телефоне

Установите MacroDroid из Play Store (бесплатной версии хватает). Создайте макрос:

**Триггер:** SMS Received (Получено SMS)
- Отправитель: номер вашего банка. Для Hamkorbank это `5800`.
- Если банков несколько — сделайте отдельный макрос на каждый номер либо укажите
  несколько отправителей в одном триггере.

**Действие:** HTTP Request
- Метод: **POST**
- URL: `https://ваш-адрес.vercel.app/api/inbox`
- Content Type: `application/json`
- Тело запроса:
  ```json
  {"text": "[sms_message]"}
  ```
  `[sms_message]` — это подстановка MacroDroid, вставляется кнопкой выбора переменных,
  а не набирается руками. Точное название посмотрите в списке Magic Text вашей версии.
- Заголовок: имя `x-wallet-key`, значение — ваш пароль.
  Если в вашей версии MacroDroid нет заголовков, добавьте пароль прямо в адрес:
  `https://ваш-адрес.vercel.app/api/inbox?key=ВАШ_ПАРОЛЬ`

**Проверка:** дождитесь любого SMS от банка (или пришлите себе перевод на 1000 сум),
затем откройте приложение. Должно само открыться окно сверки с этой операцией.

## Что делать, если не сработало

**Приложение пишет «Новых сообщений нет», хотя SMS приходило.**
Откройте в MacroDroid журнал выполнения макроса — там видно, сработал ли триггер и
какой ответ вернул сервер. Ответ `401` означает несовпадение пароля, `400` — что
в теле запроса пустой текст, то есть подстановка `[sms_message]` не подставилась.

**Сообщения приходят повторно.**
Приложение подтверждает получение только после того, как вы закрыли окно сверки.
Если закрыть приложение, не тронув окно, сообщения придут снова — это сделано намеренно,
чтобы ничего не терялось. Задвоения не будет: сверка по карте, времени и остатку
отсечёт повторы.

**Банк присылает пуш вместо SMS.**
MacroDroid умеет ловить и уведомления: триггер **Notification Received** с фильтром по
приложению банка, действие то же самое, только вместо `[sms_message]` подставляется
текст уведомления. Формат текста у пушей другой — если разбор не пойдёт, пришлите
образец, поправлю правила разбора.

## О приватности, честно

При такой схеме тексты ваших банковских SMS проходят через Vercel и лежат до месяца
в Upstash. Это ваши собственные учётные записи, никто третий к ним доступа не имеет,
но данные покидают телефон — до сих пор приложение работало полностью на устройстве.

Что стоит понимать:
- В SMS видны суммы, остатки на картах, последние 4 цифры карт и названия магазинов.
  Полного номера карты и кодов там нет.
- Пароль ящика — единственная защита. Если он утечёт, чужой человек сможет читать
  накопленные сообщения. Меняйте его при подозрениях: поменять надо в двух местах —
  в переменных Vercel и в настройках приложения.
- Сообщения удаляются сразу после того, как вы закрыли окно сверки, и в любом случае
  исчезают через месяц.

Если это не устраивает — оставайтесь на ручном варианте: «Поделиться → Wallet» или
вставка текста в приложение. Там телефон никуда ничего не отправляет, и работает это
без всякого сервера.
